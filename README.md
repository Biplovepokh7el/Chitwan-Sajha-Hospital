## 📁 File Structure

```
hospital-website/
├── index.html                  # Home Page (Hero, Centers of Excellence, Stats, Testimonials)
├── about.html                  # About Us, Hospital History, Timeline, Clinical Leadership
├── doctors.html                # Doctor Directory & Filterable Search Engine
├── doctor-detail.html          # Comprehensive Doctor Profile & OPD Schedule
├── departments.html            # Clinical Departments & Specialty Procedures
├── services.html               # Health Checkup Packages & Hospital Facilities
├── appointment.html            # Interactive 5-Step Online OPD Booking Wizard
├── blog.html                   # Medical Health Library, Breakthroughs & Articles
├── contact.html                # Location Map, Emergency Helpline, Form & FAQ Accordion
├── careers.html                # Career Openings & Medical Staff Portal
├── privacy.html                # Privacy Policy, EMR Security & Terms
├── 404.html                    # Accessible Custom 404 Error Page
├── README.md                   # Project Documentation
└── assets/
    ├── css/
    │   ├── style.css           # Core Design Tokens, Typography, Grid & Resets
    │   ├── components.css      # Component Library (Header, Search, Cards, Modals, Forms)
    │   └── animations.css      # 60 FPS Micro-interactions, Keyframes & Scroll Reveals
    ├── js/
    │   ├── data.js             # Dataset (Chitwan Sajha Hospital Doctors, Depts, FAQs)
    │   ├── main.js             # Global Controller, Toast System, Cookie Banner
    │   ├── navigation.js       # Sticky Nav, Mega Menu, Mobile Drawer & Focus Trap
    │   ├── search.js           # Live Overlay Search (Cmd+K) & Autocomplete
    │   ├── appointment.js      # Multi-step Appointment Booking Engine
    │   └── components.js       # Accordions, Tabs, Counters & Carousel Engine
    └── images/                 # High-Resolution Visual Assets
```
